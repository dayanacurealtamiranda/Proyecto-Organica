# Proyecto 5: Compuestos Carbonílicos (Aldehídos y Cetonas)

## 📌 Descripción del Proyecto
Caracterización fisicoquímica, análisis gráfico computacional y matriz de 200 transformaciones químicas (10 reacciones y 10 obtenciones por sustancia) extraídas de *CAS SciFinder-n* para compuestos carbonílicos.

### 🧪 Sustancias Analizadas
1. Acetaldehído
2. Acetona
3. Benzaldehído
4. Ciclohexanona
5. Butanona
6. Propanaldehído
7. Formaldehído
8. Acetofenona
9. Benzofenona
10. Cinnamaldehído

---

## 📁 Estructura del Repositorio
* *data/*: Base de datos en CSV (dataset_carbonilicos_200.csv) con las 200 transformaciones (CAS Reaction Number, reactivos, condiciones y 8 propiedades fisicoquímicas).
* *notebooks/*: Código ejecutable en Python (Google Colab) para el análisis estadístico y generación de gráficas.
* *report/*: Documento fuente en LaTeX (Código_fuente_LaTeX.tex) y reporte oficial en formato PDF (Informe_Proyecto5_Grupo.pdf).
* *powerbi/*: Tablero dinámico interactivo con filtros por número CAS y tipo de sustancia.
